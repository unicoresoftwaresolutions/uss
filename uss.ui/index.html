LiveApp

Play Anything, Instantly.

LiveApp is a platform for discovering and running interactive apps and games without ever installing them.

Built on a container-based application server using Docker and a lightweight, secure WebAssembly (WASM) client runtime, LiveApp lets developers publish apps and games that users can launch in seconds — no downloads, no updates, no waiting.
